# Planos de implementação

Rascunhos de planejamento (`PLAN-<issue>.md`) produzidos ANTES de implementar uma
issue — decomposição, refs verificadas no código, deltas de review de plano.

> ⚠️ **São rascunhos pré-implementação, NÃO specs vivas.** Em geral ficam
> superados pelo que de fato foi mergeado (a descrição do PR + a issue + o ADR são a
> verdade durável). Use como **arquivo histórico** do raciocínio. Quando acumular
> demais, peça uma limpa.
