# Handoffs entre sessões

Documentos de continuidade escritos ao **encerrar uma sessão de trabalho** (ver
CLAUDE.md → "Handoffs entre sessões"). Cada `HANDOFF-<issue|fase>.md` é
auto-suficiente: escopo, o que ler primeiro, ordem/dependências, princípios
inegociáveis, landmines, critério de saída — aterrado no código real.

> ⚠️ **São snapshots de um ponto no tempo, NÃO specs vivas.** Citam PRs, SHAs,
> "próxima sessão", estado do board — envelhecem rápido. A fonte de verdade durável é
> ADRs (`docs/decisions/`), issues, descrições de PR e CLAUDE.md. Use os handoffs como
> **arquivo histórico / log de sessão**. Quando acumular demais, peça uma limpa.
